== Description ==

Lexoria is a prestigious Full Site Editing theme crafted for law firms and attorneys. Deep charcoal and gold design, consultation hero, practice area grids, case result stats, attorney profiles, client testimonials, FAQ accordion and free consultation CTAs — everything a modern firm needs to win clients online.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates, curated block patterns, and style variations. Translation-ready and accessibility-conscious.
